# River Plate TV (font)

Capitals A–Z, digits 0–9, É, in Bold and Light, traced from the **River Plate Bold** and **River Plate Light**
specimens that [Grupo Berro](https://www.grupoberro.com/trabajos/club-atl%C3%A9tico-river-plate) published with
Club Atlético River Plate's 2022 identity. The lettering is the club's design.

Added to make the home screen work: colon, period, hyphen, space, Á Í Ó Ú Ñ (from the É accent), lowercase
mapped to the capitals, and tabular digits for the clock. Anything else falls back to Oswald.

Rebuild with `../../tools/build_font.py` (potrace + fontTools) from the two specimen images.
